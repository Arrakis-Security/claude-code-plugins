# Security policy

## Report a vulnerability

Report it privately through GitHub: open the [Security tab](https://github.com/Arrakis-Security/claude-code-plugins/security) of this repository and choose **Report a vulnerability**. Please don't open a public issue.

Include the plugin and its version (from `.claude-plugin/plugin.json`), your Claude Code version (`claude --version`), and the steps that show the problem. For a secret the redactor fails to hide, describe its format with a made-up value. Never send a real secret.

## Supported versions

Fixes go into the latest release of each plugin.
